# Remote Install CM-Lite-Daemon Usage Guide

This guide explains how to use the remote installation scripts for cm-lite-daemon on Cumulus devices.

## Prerequisites

1. **On BCM (this machine):**
   - Python 3.6+
   - SSH client
   - sshpass (for password authentication)
   - Access to `/cm/shared/apps/cm-lite-daemon-dist/cm-lite-daemon.zip`

2. **On target devices:**
   - SSH access
   - sudo privileges
   - Internet connectivity (for downloading packages)

## Complete Workflow

### Step 1: Add Devices to BCM

First, add your devices to BCM using the CSV file:

```bash
# Create or update cumulus.csv with your device information
# Columns: Hostname, IP, MAC, Network

# Dry run to see what will be done
python3 add_cumulus_devices_to_bcm.py --csv cumulus.csv

# Actually add devices to BCM
python3 add_cumulus_devices_to_bcm.py --csv cumulus.csv --execute
```

After adding devices to BCM, bootstrap certificates will be generated at:
- `/cm/local/apps/cmd/etc/htdocs/switch/<SWITCH_NAME>/bootstrap.key`
- `/cm/local/apps/cmd/etc/htdocs/switch/<SWITCH_NAME>/bootstrap.pem`

### Step 2: Transfer CM-Lite-Daemon

Transfer the daemon and dependencies to each device:

```bash
# Transfer files to the device
python3 transfer_cm_lite_daemon.py --host 10.141.1.100 --username cumulus --password 1234

# Or using SSH key
python3 transfer_cm_lite_daemon.py --host 10.141.1.100 --ssh-key ~/.ssh/id_rsa
```

### Step 3: Install and Configure CM-Lite-Daemon

Install the daemon and optionally transfer bootstrap certificates:

```bash
# Basic installation (without bootstrap certificates)
python3 remote_install_cm_lite.py --host 10.141.1.100 --username cumulus --password 1234

# Installation with bootstrap certificate transfer
python3 remote_install_cm_lite.py --host 10.141.1.100 --username cumulus --password 1234 \
    --switch-name switch1 --transfer-bootstrap

# Using SSH key authentication
python3 remote_install_cm_lite.py --host 10.141.1.100 --ssh-key ~/.ssh/id_rsa \
    --switch-name switch1 --transfer-bootstrap

# Complete setup with node registration
python3 remote_install_cm_lite.py --host 10.141.1.100 --username cumulus --password 1234 \
    --switch-name switch1 --transfer-bootstrap --register-node --bcm-master-ip 10.141.1.5
```

## Bootstrap Certificate Transfer

The `--transfer-bootstrap` option automatically:

1. **Waits for bootstrap files** to be generated by BCM (up to 2 minutes with progress updates)

2. **Checks for bootstrap files** on BCM at:
   ```
   /cm/local/apps/cmd/etc/htdocs/switch/<SWITCH_NAME>/bootstrap.key
   /cm/local/apps/cmd/etc/htdocs/switch/<SWITCH_NAME>/bootstrap.pem
   ```

3. **Transfers files** to the target device using SCP

4. **Installs certificates** to:
   ```
   /opt/cm-lite-daemon/etc/bootstrap.key  (permissions: 600, owner: root:root)
   /opt/cm-lite-daemon/etc/bootstrap.pem  (permissions: 644, owner: root:root)
   ```

### Requirements for Bootstrap Transfer

- `--switch-name` must be provided (must match the switch name used in BCM)
- `scp` command must be available
- Bootstrap files must exist on BCM (generated after adding device to BCM)

## BCM Master IP Auto-Detection

When using `--register-node`, the script can automatically detect the BCM master IP using the `cmsh` command:

```bash
cmsh -c 'device; use master; get ip'
```

**Auto-detection is enabled when:**
- `--register-node` is specified
- `--bcm-master-ip` is NOT provided
- Script is running on a BCM system with `cmsh` available

**Manual IP specification:**
- Use `--bcm-master-ip` to override auto-detection
- Useful when running from non-BCM systems or custom setups

## BCM Node Registration

The `--register-node` option provides complete automation by:

1. **Auto-detecting BCM master IP** using `cmsh` (if not provided manually)
2. **Running registration command**: `sudo ./register_node --host <BCM_IP> --disable-cert-check`

### Requirements for Node Registration

- `--switch-name` must be provided (bootstrap certificates required)
- Bootstrap certificates must be transferred (automatically enabled with `--register-node`)
- BCM master must be accessible from the target device

### Usage Examples for Node Registration

```bash
# Register with BCM master IP auto-detection (recommended)
python3 remote_install_cm_lite.py --host 10.141.1.100 --username cumulus --password 1234 \
    --switch-name spine01 --register-node

# Register with BCM master IP explicitly provided
python3 remote_install_cm_lite.py --host 10.141.1.100 --username cumulus --password 1234 \
    --switch-name spine01 --register-node --bcm-master-ip 10.141.1.5

# Register with custom BCM master name
python3 remote_install_cm_lite.py --host 10.141.1.100 --username cumulus --password 1234 \
    --switch-name spine01 --register-node --bcm-master-name bcm-server --bcm-master-ip 10.141.1.5
```

## Command Line Options

### remote_install_cm_lite.py

```bash
python3 remote_install_cm_lite.py [OPTIONS]

Required:
  --host IP_OR_HOSTNAME        Target device IP or hostname

Authentication (choose one):
  --password PASSWORD          SSH password
  --ssh-key PATH              Path to SSH private key

Optional:
  --username USER             SSH username (default: cumulus)
  --sudo-password PASS        Sudo password (defaults to SSH password)
  --os-type TYPE              Target OS (auto|debian|rhel|centos|fedora|suse)
  --home-dir PATH             Home directory (default: /home/username)
  --install-dir PATH          Installation directory (default: /opt)

Bootstrap Certificate Transfer:
  --switch-name NAME          Switch name for bootstrap files (required for --transfer-bootstrap)
  --transfer-bootstrap        Transfer bootstrap certificates from BCM

Node Registration:
  --register-node             Register node with BCM master
  --bcm-master-ip IP         IP address of BCM master (optional - auto-detects using cmsh if not provided)
  --bcm-master-name NAME     Custom name for BCM master (optional)
```

## Example Complete Workflow

```bash
# 1. Add device to BCM
python3 add_cumulus_devices_to_bcm.py --csv cumulus.csv --execute

# 2. Transfer daemon to device
python3 transfer_cm_lite_daemon.py --host 10.141.1.10 --username cumulus --password 1234

# 3. Install daemon with bootstrap certificates and register with BCM (auto-detects BCM IP)
python3 remote_install_cm_lite.py --host 10.141.1.10 --username cumulus --password 1234 \
    --switch-name spine01 --register-node

# Alternative: Manual steps (without --register-node)
python3 remote_install_cm_lite.py --host 10.141.1.10 --username cumulus --password 1234 \
    --switch-name spine01 --transfer-bootstrap
# Then manually: ssh cumulus@10.141.1.10 "cd /opt/cm-lite-daemon && sudo ./register_node --host master --disable-cert-check"
```

## Troubleshooting

### Bootstrap File Not Found
```
Bootstrap files not found after 120 seconds:
  - bootstrap.key at /cm/local/apps/cmd/etc/htdocs/switch/spine01/bootstrap.key
  - bootstrap.pem at /cm/local/apps/cmd/etc/htdocs/switch/spine01/bootstrap.pem

Possible causes:
  1. BCM initialize process is still running (check 'cmsh -c "device; show"')
  2. Device was not properly added to BCM
  3. Switch name 'spine01' doesn't match the name in BCM
  4. BCM bootstrap generation failed
```
**Solution:** 
- The script now automatically waits up to 2 minutes for bootstrap files to be generated
- Check BCM device status: `cmsh -c 'device; show'`
- Verify the switch name matches exactly what was used in BCM
- Ensure the device was successfully added and initialized in BCM

### Node Registration Failed
```
⚠ Node registration failed or returned non-zero exit code
```
**Solution:** 
- Check BCM master connectivity: `ssh cumulus@10.141.1.10 "ping master"`
- Verify /etc/hosts entry: `ssh cumulus@10.141.1.10 "cat /etc/hosts | grep master"`
- Check register_node exists: `ssh cumulus@10.141.1.10 "ls -la /opt/cm-lite-daemon/register_node"`

### BCM Master Not Reachable
```
Error getting BCM master IP: IP address cannot be empty
```
**Solution:** Provide BCM master IP using `--bcm-master-ip` argument or ensure network connectivity.

### SCP Permission Denied
```
Error: SCP command failed
```
**Solution:** Check SSH credentials and ensure the user has proper permissions.

### Missing Tools
```
Error: Missing required tools: scp
```
**Solution:** Install missing tools:
```bash
# Ubuntu/Debian
sudo apt install openssh-client

# RHEL/CentOS
sudo yum install openssh-clients
```

### BCM Master IP Auto-Detection Failed
```
Failed to detect BCM master IP using cmsh command: [Errno 2] No such file or directory: 'cmsh'
```
**Solution:** 
- Ensure you're running the script on a BCM system with `cmsh` available
- Or manually specify the BCM master IP using `--bcm-master-ip <IP_ADDRESS>`

```
Failed to detect BCM master IP using cmsh command: Command 'cmsh -c device; use master; get ip' returned non-zero exit status 1
```
**Solution:** 
- Check BCM cluster status: `cmsh -c 'cluster; show'`
- Verify BCM master is configured and accessible
- Use `--bcm-master-ip` to specify IP manually

## Security Notes

- Bootstrap certificates contain sensitive cryptographic material
- Files are transferred with restricted permissions (600 for .key, 644 for .pem)
- All files are owned by root for security
- Temporary files are automatically cleaned up during transfer
